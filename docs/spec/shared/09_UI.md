# UI ARCHITECTURE — CANONICAL SPEC v0.1

Estado: **CANONICAL**
Skin visual final: **ITERATIVE**

## Shell común

```text
HEADER
GRID
6 MACROS
ACTION STRIP
DETAIL PANEL
```

Prioridad:

```text
1 Pattern
2 Generate/Evolve
3 Macros
4 Engine/Root/Scale
5 Details
```

## Header

```text
ENGINE
ROOT
SCALE
LENGTH
pending/status
```

La UI consulta `EngineCapabilities`.

No mostrar lengths ilegales.

Scale:

```text
disabled/secondary si scaleRelevant=false
```

## Grid

Representa siempre:

```text
CURRENT PATTERN
```

Nunca un preview especulativo de TARGET.

16 steps principal.
32 steps ELECTRONIC:

```text
2 filas de 16
```

Step resume:

```text
state
harmonic intent
register
lock
selection
```

## Overlays

ELECTRONIC:
```text
motif / copy / variation blocks
```

BODY:
```text
A | B | A | B'
```

MACHINE:
```text
cell starts
bar grid
re-anchor markers
```

## Macros

ELECTRONIC:
```text
DENSITY REPEAT SYNC VARIATION OCTAVE TENSION
```

BODY:
```text
DENSITY REPEAT SYNC VARIATION OCTAVE TENSION
```

MACHINE:
```text
DENSITY REPEAT PHASE ANCHOR GAP VARIATION
```

Mover macro:

```text
TARGET only
```

Cada macro puede mostrar:

```text
target position
+
small applied marker
```

## Actions

Primarias:

```text
GENERATE
EVOLVE
```

Secundarias:

```text
UNDO
SET BASE
```

Control:

```text
EVOLVE AMOUNT
```

EVOLVE enabled sólo si:

```text
current exists
target engine == current engine
target length == current length
```

## Detail tabs

```text
PATTERN
PITCH
EVOLVE
```

PATTERN:
```text
NOTE/REST/TIE
full step lock
```

PITCH:
```text
PitchIntent
register
```

Sólo mostrar vocabulary legal del engine.

EVOLVE:
```text
mutation scope
partial locks
set base
```

## Current / Target visual rule

```text
CURRENT = grid
TARGET = header/macros
APPLIED = markers
```

No duplicar dos interfaces.

## Max UI responsibility

UI:

```text
render
read interaction
emit application commands
```

No:

```text
metrics
archetype selection
pitch resolution
grammar validation
```

```text
header
grid
6 macros

```

No incluir aún:

